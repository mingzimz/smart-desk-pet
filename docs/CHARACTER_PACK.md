# 角色包协议 v1

一个自定义角色对应数据目录 `characters/<角色ID>/` 下的子目录。角色 ID 使用字母、数字、下划线或短横线，最多 80 字符；目录名是稳定身份，用来关联人设与记忆。不要随意重命名已使用的角色目录。

## 文件布局

```text
characters/my-pet/
  character.json
  idle/00.png
  idle/01.png
  happy/00.png
  angry/00.png
  sleepy/00.png
```

`character.json` 示例（对应文件必须真实存在）：

```json
{
  "schema_version": 1,
  "name": "我的桌宠",
  "animations": {
    "idle": { "fps": 8, "frames": ["idle/00.png", "idle/01.png"] },
    "happy": { "fps": 12, "frames": ["happy/00.png"] },
    "angry": { "fps": 8, "frames": ["angry/00.png"] },
    "sleepy": { "fps": 6, "frames": ["sleepy/00.png"] }
  }
}
```

idle 必填，其余缺失时使用 idle。帧按清单顺序循环，支持每组不同 FPS。动画速度设置在基础 FPS 上乘以 0.25–3.0。

## 资产约束

- 推荐每帧 320×320 的透明 PNG，人物脚底和中心对齐，四周留出呼吸、摇摆所需边距。
- 每状态 1–48 帧，FPS 1–30，角色名称 1–60 字符。
- 单文件不超过 16 MB，原图不超过 4096×4096；加载后缩放至 320 范围内。
- 相对路径必须落在角色包目录内，不允许 `../` 越界或绝对路径指向外部。
- 清单必须小于 128 KB。首版不支持 ZIP 导入、sprite atlas、嵌入脚本或网络资源。

把角色包放入数据目录后重新打开设置即可列出；选中并保存时加载和验证帧。已选择角色损坏时启动回退到内置猫并显示提示，旧记忆仍保留。

## 单图生成

设置 → 角色与外观 → 导入图片，选择 PNG/JPG/WebP 并命名。系统把图像缩放到角色画布，生成四组各 8 帧运动：idle 呼吸，happy 上下跳动，angry 小角度摇摆，sleepy 轻微倾斜。所有帧和 manifest 完成后才把角色目录加入目录列表。

导入只使用本地图片，不上传网络。保留原始背景；透明素材会保留透明度。它不会重新绘制表情、补齐姿态、抠图或生成新角色身份。用户可后续将同路径 PNG 换成自己制作的完整表情动画。

导入产生角色包后，即便取消设置，该包仍保留供以后选择；只有“保存并应用”才改变当前角色。内置角色是运行时代码绘制，不在此目录中。
