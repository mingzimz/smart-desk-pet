# 两个月开发计划（8 周）

按 1 名主要开发者、可获得基本美术支持估算。当前框架已提供贯通基础链路；下列安排用于把框架打磨成可演示、可交付版本。每周保留约 20% 时间处理集成问题，不把生成式动画和语音同时纳入首版。

## 第 1 周：工程与桌面宿主

任务：确认运行目标 Windows 10/11，规范目录和配置 schema；验证透明置顶、拖拽、可见区域恢复、托盘及单实例；确定内置美术来源。

验收：干净 Python 环境可启动，所有窗口可以通过托盘恢复和退出，重启保留坐标；建立自动化测试和 Windows CI。

## 第 2 周：角色动画与导入

任务：确认角色包协议，替换或完善两个内置角色的四类动画；测试单图导入、透明 PNG、异常大图、缺失状态与目录损坏；检查动画速度和隐藏时资源占用。

验收：两个固定形象可切换；用户导入图片后能直接使用；错误角色包不会使主程序崩溃；真实桌面上无明显闪烁。

## 第 3 周：模型链路

任务：连接本机 Ollama 和至少一个真实兼容 API；明确支持的服务参数，完善错误文案；验证超时、取消、断网、模型不存在、认证失败与退出期间请求。

验收：模型推理时持续拖拽不卡顿；连续 30 次对话无串话；取消后晚到结果丢弃。若资源允许，可在本周末增加流式输出原型。

## 第 4 周：人设、情绪与记忆

任务：根据试用反馈调节心情/精力规则；完善角色不同人设；验证每个角色记忆隔离、记录上限、清除与重启恢复；补充长对话上下文策略。

验收：同一条正面、负面和休息消息产生可解释变化；不会在状态边界闪烁；角色切换不会继承其他角色的记忆。

## 第 5 周：设置与完整交互

任务：完善表单校验、数据保存错误反馈、首次使用引导、托盘显隐；调节聊天面板和角色位置关系；检查 125%/150%/200% DPI。

验收：所有要求中的设置可修改并立即生效，重启后保持；取消设置不改运行配置；UI 不显示模型原始错误堆栈或密钥。

## 第 6 周：稳定性与性能

任务：长时间运行、多显示器拔插/主屏变更、休眠唤醒、连续导入与切换；记录空闲 CPU、内存、动画流畅度和模型等待状态；完成测试缺口。

验收目标：约定基准机器上运行 4 小时无崩溃，隐藏桌宠时停止动画；内存不随成功对话次数持续增长。建议目标为空闲 CPU <3%、桌宠本体内存 <250 MB，不含模型进程，需实测确认。

## 第 7 周：打包与交付候选版

任务：PyInstaller 打包、干净 Windows 虚拟机测试；核查用户数据路径、卸载后数据策略、开源许可证和美术授权；如需安装器和签名，本周完成。

验收：未安装 Python 的机器能运行；模型服务未配置时可以演示；完整目录分发、重启与退出均正常。未具备签名预算时明确提供未签名内部测试版。

## 第 8 周：验收、修复与演示

任务：按需求逐条回归，修复高优先级问题；冻结功能；输出演示流程、用户手册、架构说明与下一版本清单。

验收：通过 TESTING.md 的 Windows 人工验收，测试和构建通过，真实模型记录完备，已知限制明确。至少保留 3 个工作日用于修复，避免最后一周新增主要功能。

## 范围取舍

首版必须：透明拖拽、四状态动画、双对话接口、分角色人设与 JSON 记忆、情绪/精力、托盘、设置、单图导入。

可选增强：流式输出、点击动画、记忆摘要、角色缩放、更多固定角色。

后续版本：生成式姿态动画、自动抠图、语音识别与合成、多模态感知、桌面操作插件、日程提醒、语义长期记忆、自动更新。

单图自动生成多种姿态不是简单帧动画问题，依赖生成模型、风格一致性与成本控制，应单独立项；当前导入以基础运动帧完成可用闭环。
